# 1. Введение в Stack-Project

В рамках проекта Stack-Project была реализована мини-библиотека для работы со стеком

Стек - структура данных, работающая по принципу LIFO (Last In - First Out)



# 2. Возможности

В библиотеке реализованы несколько функций для работы со стеком:

(1) - stack_constructor() - Инициализатор стека по указателю

(2) - stack_push() - Функция добавления элемента в стек

(3) - stack_pop() - Функция взятия из стека последнего добавленного элемента (из находящихся в стеке)

(4) - stack_destructor() - Удаление стека

(5) - stack_dump() - Подробная печать информации о стеке (осуществляется в файл)

(6) - stack_verify() - Подробная проверка стека

(7) - stack_print() - Печать содержимого стека (осуществляется в терминал)

(8) - stack_user_verify() - Функция проверки стека с возможностью её пропуска (обёртка для функции stack_verify())


Для работы выше перечисленных функций реализованы вспомогательные функции:

(2.1) - stack_raise() - Используется в функции stack_push() для увеличения размеров стека

(3.1) - stack_cut() - Используется в функции stack_pop() для уменьшения размеров стека

(6.1) - hash_djb2() - Используется функцией stack_verify() для хэширования структуры, содержащей сам стек и информацию о нём



# 3. Логирование

В данном проекте значительную роль играет реализация логирования

Логирование — это процесс записи событий, происходящих в программе, системе или инфраструктуре, чтобы потом анализировать работу, искать ошибки и понимать, что происходило в конкретный момент

Реализацию можно посмотреть в файле stack_logging.cpp


# 4. Требования и сборка

Для запуска программы потребуется компилятор языка **C/C++** (К примеру, g++/clang++)

Потребуется файл (к примеру stack_main.cpp), в котором будет реализована функция main(), работающая со стеком

Также потребуется файл, куда будет записываться вся информация о процессах, происходящих со стеком (к примеру, log_file.txt)

Чтобы все функции корректно работали, следует не забыть включить stack_operations.cpp в a.cpp строкой 
``` bash
#include "stack_operations.cpp"
```
И открыть поток записи в файл:
``` bash
log_init("log_file.txt");
```

Команда для сборки в терминале:
``` bash
g++ stack_main.cpp -o stack_main.exe
```

При этом файлы stack_main.cpp; stack_operations.cpp; stack_logging.cpp должны находиться в одной папке

Следует проверить, "находится" ли пользователь в папке, содержащей проект (для windows: ls .). Если нет, то для начала следует перейти в нужную папку


# 5. Запуск и использование

После сборки следует написать в терминале 
``` bash
.\stack_main.exe
```

для запуска программы
